The Black Chamber

London, 1586. You read the realm’s sealed letters for Sir Francis Walsingham. Six intercepted dispatches sit in the drawer; each is written in cipher.

  • Every glyph stands for one letter of the alphabet.
  • Tap a glyph, then pick its true letter from the tray — or simply type it.
  • A glyph already claimed swaps places; backspace lets go of a letter.
  • When the reading is complete and true, the dispatch is sealed and sent.
  • The candle burns as you think. A false full reading scorches it. Wax buys one true hunch.
  • Six seals before six candles die, and the realm stands.

How to play

  • A–Z set the glowing glyph’s letter
  • ← → or tab move between glyphs
  • backspace clears a letter  ctrl+Z undoes
  • esc pauses; the buttons above run hint, sound and new run
